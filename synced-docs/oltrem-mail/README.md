# Oltrem Mail

The email part of an Oltrem portal: sending through an email provider (the default From address and
the provider's key) or through Cloudflare's own email (one button), templates, lists, campaigns,
and an optional inbox on the business's own domain, all on Cloudflare's free plan.

**Status:** the plan was approved on 2026-11-02, and its five phases were built that day: the
email and campaigns modules moved here, the Cloudflare route and Mail setup, the simple provider
card, the inbox, and consent with the warm-up (the records are listed in
[docs/README.md](docs/README.md)). Start with [ai.md](ai.md), then the plan in
[docs/plan.md](docs/plan.md).

This repository is private. It is packed into each client's repository next to the Oltrem kit,
with no registry and no public package. Its documents are public: each pack carries them, and the
kit's docs mirror publishes them in their own folder ([docs/README.md](docs/README.md) says how).
