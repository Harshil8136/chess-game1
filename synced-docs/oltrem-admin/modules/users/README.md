# @oltrem/users

The people of a client Worker: the directory with each person's profile, switching an account off
and on, blocking sign-in and ending sessions under the permission model's standing rules, sign-in
history, saved views and notifications. An account is the IAM module's principal row; this module
adds what a person is called and how they read the portal. Invitations, groups and API keys'
service accounts are `@oltrem/iam`'s.
