# @oltrem/files

The company's files: a drive for each place of the company, with folders, kept in the client's one
bucket. Who may open, change or share a file is never a list kept on the file: it is the roles held
at the file's place, the same roles that decide everything else in the portal. Give someone a role
at a place and its files open to them at once; end the role and they close. There is no second
permission system to keep in step.
